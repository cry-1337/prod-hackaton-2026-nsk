# Документация «Вместе»

«Вместе» — сервис групповых закупок. Покупатели выбирают количество товара и максимальную цену за единицу. Итоговая цена зависит от объёма подходящих заявок.

| Документ | Что в нём искать |
| --- | --- |
| [group-purchases.md](group-purchases.md) | Правила MVP и критерии приёмки. Как работает «Куплю до», при каком объёме сбор закрывается, когда покупателю возвращают деньги и какой подарок получает организатор. |
| [user-story-map.md](user-story-map.md) | Карта пользовательских историй. Показывает путь покупателя и организатора от поиска товара до получения заказа или возврата. |
| [architecture.md](architecture.md) | Устройство всей системы. Как запрос проходит от браузера до PostgreSQL, как бэкенд обрабатывает одновременные покупки, как устроены чат, мониторинг и выкладка на стенд. |
| [frontend-architecture.md](frontend-architecture.md) | Устройство React-клиента. Какие страницы доступны по каждому маршруту, где хранятся данные формы и кеш запросов, как клиент подтверждает предоплату и восстанавливает соединение с чатом. |
