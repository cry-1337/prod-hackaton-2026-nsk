# Вместе

React-клиент групповых покупок. Витрина, публичные ссылки `/groups/{код}` и личный кабинет используют один и тот же Backend API под `/api`.

[Спецификация MVP и архитектура проекта](https://gitlab.t-education.com/hack-ovb-02/specs/)

Локальный Vite проксирует `/api` на `http://127.0.0.1:5080`. Адрес бэкенда для разработки задаётся через `API_PROXY_TARGET`. На стенде маршрутизацию выполняет общий Caddy.
