# Вместе

Проект «Вместе» занял **1-е место на хакатоне PROD 2026 в Новосибирске**. Команда № 2 набрала **26,24 балла**, в том числе **9,67 балла за бэкенд** — лучший результат по этому блоку. [Полная таблица результатов (.xlsx)](Результаты_Новосибирс.xlsx)

«Вместе» — сервис групповых закупок для кейса Т-Шопинга. Организатор выбирает товар, создаёт сбор и приглашает участников по ссылке. Покупатели указывают количество товара и максимальную цену за единицу. Итоговая цена зависит от объёма заявок, подходящих под ценовую ступень. При успешном сборе организатор получает подарок, а при отмене участникам возвращается предоплата.
